My Daily Routine - Android Studio project

এই ফোল্ডারটি Android Studio-তে Open করে APK তৈরি করা যাবে।

APK বানানোর ধাপ:
1. Android Studio ইনস্টল করুন।
2. File > Open থেকে MyDailyRoutine ফোল্ডারটি নির্বাচন করুন।
3. Gradle Sync শেষ হতে দিন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
5. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk-তে তৈরি হবে।

ব্যবহার:
- + Add Routine চাপুন।
- কাজের নাম লিখুন এবং সময় বেছে Save করুন।
- Android 13+ হলে Notification permission Allow করুন।
- ফোনের Settings-এ App-এর Alarms & reminders / Exact alarms অনুমতি চাইলে Allow করুন।
- Delete দিয়ে রুটিন মুছতে পারবেন।

নোট: Android-এর Battery Saver/কিছু নির্মাতার battery optimization alarm দেরি করাতে পারে। নির্ভরযোগ্য অ্যালার্মের জন্য অ্যাপের notification ও exact alarm অনুমতি চালু রাখুন।
